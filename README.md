# Landing Page Microsoft Surface bằng Bootstrap

Bài tập thiết kế Landing Page theo phong cách Microsoft Surface bằng Bootstrap 5.3.

## Công nghệ

- HTML5
- Bootstrap 5.3 qua CDN
- Bootstrap Icons
- CSS tùy chỉnh tối thiểu cho hình nền và kích thước hình ảnh

## Chạy dự án

Mở trực tiếp `index.html` trên trình duyệt hoặc chạy một HTTP server tĩnh trong thư mục dự án.

Trang gồm navbar responsive, hero section, các lợi ích, card sản phẩm Surface, section tính năng và footer.
